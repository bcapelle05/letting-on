Letting On

Wildfire Hollow Studios

I made this game inspired by my last internship. It looks like a simple 2D office game about being the new intern, but underneath it is disguised as a mystery puzzle game. You do the daily tasks, run errands, and help coworkers, and little pieces start to connect if you pay attention and write things down.

It is not really a one run game. I built it for around 3 runs to get the most out of it. The first run is learning the office, and the next runs are where the different choices, paths, and endings start to make sense.
